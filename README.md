Real-Time Chat App

Real-Time Chat App is a full-stack web application built with Node.js, React, Socket.io, and MongoDB, allowing users to chat instantly with real-time updates. The app supports sending text messages, images, and includes theme selection for a personalized experience.

Features
Chat Functionality

Real-time messaging using WebSockets (Socket.io)

Send images along with text messages

Multiple users can chat simultaneously

Typing indicators (optional)

User Experience

Theme selection: Light and Dark mode support

Responsive UI: Works on desktop and mobile devices

Backend & Data

Node.js & Express for backend server

Socket.io for real-time WebSocket communication

MongoDB to store chat history and user data

Technology Stack

Backend: Node.js, Express, Socket.io

Frontend: React.js, Tailwind CSS (or specify your styling library)

Database: MongoDB

Real-Time Communication: WebSockets via Socket.io

How It Works

User Authentication: Users log in or join a chat room

Real-Time Chat: Messages are sent and received instantly via WebSocket

Media Sharing: Users can upload and send images in chat

Theme Selection: Users can switch between Light and Dark mode
